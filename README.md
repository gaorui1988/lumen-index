# Lumen Index

A single-page homepage for Lumen Index, a library of original vibe-coding website templates. Each template is a live demo plus the prompt and DESIGN.md that built it. The page is dark and technical: near-black panels, hairline borders, mono labels, and one acid-lime accent.

Built from the [VibeFather](https://vibefather.ai/t/template-library-landing-page) template **Template Library Landing Page** (CC BY-NC 4.0). Personal and non-commercial use includes the footer credit. Commercial use needs a [VibeFather Pro](https://vibefather.ai/pricing) license.

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

`npm run build` writes static files to `dist/`. There is no backend.
